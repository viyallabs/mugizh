# Country-pack configuration model (S-054)

**Phase P05 · Epic EP07 · Depends on:** S-036 · **Contract refs:** K-GLB-01, K-GLB-03 (also K-GLB-02, K-CS-07, K-PAY-05, K-MSG-01, K-DP-08) · **Edge case:** E-GLB-01 · **Compliance:** C32 · **Date:** 2026-11-15
**Status:** Done (acceptance criterion: schema written; India pack drafted). The values in the India pack still carry the founder, lawyer, CA and doctor items from their source documents.

**Who this is for:** developers building the config loader (S-099) and anything that reads country rules; reviewers approving pack changes.

**Draft India pack:** [country-packs/IN/pack.draft.yaml](country-packs/IN/pack.draft.yaml). It moves to `config/country-packs/IN/` when the repo exists (S-090, S-099).

## 1. What a country pack is

Everything that changes by country lives in one versioned folder (K-GLB-01): laws, drug lists, retention periods, emergency numbers, currency, identity rules, providers and legal texts. **Code holds none of these values.** A new market is a new pack plus new adapters, not a code change (E-GLB-01).

```
config/country-packs/IN/
  pack.yaml                          # the manifest (this model, section 2)
  rules/telemedicine-rules.yaml      # prescribing decision tables (S-012)
  drugs/classification.yaml          # drug-to-list map, own version (S-126)
  payments/refund-policy.yaml        # refund policy (S-019)
  messaging/sms-templates.yaml       # DLT template registry (S-021)
  legal/                             # notice and consent text versions, terms, grievance details
  i18n/                              # country-specific strings (shared strings live in the apps)
```

## 2. Manifest schema (`pack.yaml`)

Every key is required unless marked optional. Types: `str`, `int`, `bool`, `list`, `map`, `ref` (a path to another pack file), `semver`.

| Section | Key | Type | Meaning | Who approves a change |
|---|---|---|---|---|
| **pack** | `code` | str (ISO 3166-1 alpha-2) | Country, e.g. `IN` | Founder |
| | `version` | semver | Pack version; **published versions are immutable** | — |
| | `status` | `draft` / `approved` / `retired` | Only `approved` packs load in production | Founder |
| | `checksums` | map file → SHA-256 | The loader verifies every referenced file (TM-18) | Generated by CI |
| **residency** (K-GLB-03, K-DP-01) | `region_primary`, `region_dr` | str | Cloud region IDs **inside the country** | Founder + infra |
| | `vendor_processing_must_be_in` | list of country codes | The loader refuses any adapter whose vendor processes data elsewhere, unless it is listed in `residency.exceptions` | Founder + lawyer |
| | `exceptions` | list (vendor, data, reason, approved_by) | Known exceptions, e.g. push via Google and Apple with no health data | Lawyer |
| **locale** | `default_locale`, `supported_locales`, `launch_locales` | str, list, list | Languages available vs shipped (K-GLB-02) | Founder |
| | `legal_text_languages` | str or list | Languages the legal texts (notices, consent, terms, grievance page) must be offered in, where the law requires a choice (India: Eighth Schedule languages) | Lawyer |
| | `default_time_zone` | IANA zone | e.g. `Asia/Kolkata` (K-ARC-04) | — |
| | `date_format`, `units` | str | Display only; storage stays UTC and ISO | — |
| **money** | `currency` (ISO 4217), `minor_units` | str, int | e.g. INR, 2 | — |
| | `tax` | ref | CA-signed tax config (rates, invoice rules) | **CA** |
| **people** | `age_of_majority`, `min_account_age` | int | 18 and 18 in India (CH-01) | Lawyer |
| | `phone_country_codes` | list | Accepted sign-in numbers, e.g. `+91` (TM-02) | Founder |
| | `prohibited_identifiers` | list (id, validator) | Identifiers that must be rejected and scrubbed, e.g. Aadhaar (Verhoeff), VID | Lawyer |
| **emergency** (K-CS-06) | `primary_number`, `other_numbers` | str, list | Dialled directly by the phone, never through our servers | Clinical reviewer |
| **clinical** | `prescribing_rules` | ref | Decision tables (K-CS-02) | **Clinical reviewer** (K-CS-07) + lawyer |

| | `minors_supported` | bool | `false` in India v1.0 (product decision) | Founder |

| **payments** | `settlement_modes_allowed` | list | e.g. `clinic_collected`, `pay_at_clinic` | Founder |
| | `refund_policy` | ref | Versioned policy (K-PAY-05) | Founder + lawyer |
| | `adapter` | str | Payments adapter ID | Founder |
| **messaging** | `channels_enabled` | map channel → bool | e.g. `whatsapp: false` while on hold | Founder |
| | `sms_registry` | ref | DLT template registry (K-MSG-01) | Founder |
| | `sms_principal_entity_id` | str | DLT Principal Entity ID | Founder |
| | `quiet_hours` | {start, end} | Non-critical messages held (K-MSG-03) | Founder |
| **legal** | `grievance` | map | Officer details and timelines | Lawyer |
| | `notice_versions`, `consent_text_versions` | map | Versions of the privacy notices and consent texts in force | Lawyer |

| **features** | `<flag>` | bool | Country-level availability, e.g. symptom search, SOS. Feature flags still apply on top (ADR-23). | Founder |

## 3. Loader rules (S-099)

1. **Validate before use.** The manifest and every referenced file are checked against their schemas and checksums. **Any failure stops the service from starting.** It never runs on partial config (fail closed).
2. **Production loads only `status: approved` packs.** Staging may load drafts, marked "DRAFT" in the Admin console.
3. **Versions are pinned and recorded.** The rule-set version, drug-classification version, refund-policy version and notice versions are stored with every prescription, booking and consent (K-CS-02, K-PAY-05).
4. **Adapters are enabled only when** the vendor is in the vendor register with a processor agreement, and its processing country is allowed by `residency` (K-DP-08, K-GLB-03).
5. **No country values in code.** A CI check rejects literals such as `"+91"`, `"112"`, `"INR"`, `"Asia/Kolkata"`, or Schedule names outside pack files and tests (S-092).
6. **Change process:** a PR that changes a pack file needs the approver named in section 2. CI regenerates checksums and runs the pack tests, including a test per rule-table row. The published version is then frozen.
7. **Test pack `XX`** (synthetic country, different currency, emergency number and drug table) runs in CI to prove no core code depends on India values (TC-53, E-GLB-01).

## 4. What is *not* in a pack

- Secrets and credentials (secrets manager).
- Per-clinic settings (database).
- Feature flags for gradual rollout (flag service).
- Shared UI strings (app i18n bundles).

The pack holds rules and references only.
